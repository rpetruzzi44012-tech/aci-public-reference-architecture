# Architectures of Coherent Intelligence: Public Reference Architecture

Architectures of Coherent Intelligence (ACI) is a reasoning and implementation discipline for preserving distinctions among evidence, memory, coherence, scale, authority, review, and state change. This repository is a curated reference architecture and evidence trail. It is not a claim that the underlying language model architecture has changed.

## How ACI Developed

- **Torch & Flame inheritance:** philosophical and architectural source material that motivated the discipline.
- **Phases 0-7:** preserved developmental architecture, including formal and pseudocode foundations.
- **Phase 8:** the complete governing pseudocode module canon.
- **Phase 9:** the accepted Minimal ACI v0.1 reference implementation.
- **Phase 10:** a closed experimental refinement phase for a local model adapter, with bounded repair-family evidence.
- **Phase 11:** integration of the Phase 8 module set. Stage 7 is the highest accepted Build Stage at the frozen source boundary for v0.1.0.

## What Is Implemented and Accepted

The curated [Minimal ACI v0.1 implementation](reference_implementations/minimal_aci_v0.1/) is accepted within its stated scope. Phase 11 Stages 1-7 have accepted historical summaries. Stage 8 is active but unaccepted and is intentionally absent from this public tree.

## Experimental and External Evidence

Phase 10 material documents experimental adapter-layer repairs; it does not replace the accepted Minimal ACI core. [Public Benchmark 001](evidence/public_benchmarks/ACI-PUBLIC-BENCHMARK-001-IFEVAL/) preserves 126 complete paired cases and does not claim a complete 541-prompt IFEval score.

## Unearned Boundaries

Phase 11 is not complete. Phase 12 continuity, Phase 13 functional identity, Phase 14 ARC work, consciousness, personhood, general intelligence, and ARC success are not claimed.
