# Phase 11: Full-Module Integration

Phase 11 integrates the full Phase 8 module set through sequential governed Build Stages. At the frozen source boundary, Stage 7 is the highest accepted stage.

- `scope/` contains the selected Phase 11 scope and build-order records.
- `accepted_stages/` contains byte-exact historical summaries paired with generated status wrappers.
- `STATUS_AND_ROADMAP.md` at the repository root is the current public-status authority.

Stage 8 is active and unaccepted. Its candidate code, contracts, GHPs, and evidence are intentionally excluded. Operational workflow machinery remains private. The cumulative executable Stage 7 R2 projection is deferred pending its exact external seal-evidence boundary.
