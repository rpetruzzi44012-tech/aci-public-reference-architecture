# Governed Engineering Methodology

ACI is developed through a governed engineering workflow that separates review, authority validation, planning, mutation, verification, preservation, acceptance, and publication.

The current Workflow Draft 7 publication body is deferred because it is not present in the frozen private source repository. It has not been imported from Drive or treated as repository-effective. That absence does not invalidate the accepted architecture published here. A future workflow publication will be versioned independently after a separate authorized adoption boundary.
