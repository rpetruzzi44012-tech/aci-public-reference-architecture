# License Scope

This public reference architecture uses path-based licensing.

## Apache License 2.0

The root `LICENSE` applies to original executable ACI software, tests, examples, and software configuration, including the curated implementation under `reference_implementations/`.

## Creative Commons Attribution 4.0 International

The root `LICENSE-DOCUMENTATION` applies to original ACI prose, canons, architectural documentation, diagrams, benchmark reports, public lessons, generated catalogs, navigation, and provenance documentation.

## Third-Party Material

Project-wide licensing applies only where Robert “Joseph” Petruzzi holds sufficient rights. Third-party material retains upstream terms. References do not imply redistribution of upstream model weights, datasets, benchmark assets, software, or source bodies. See `THIRD_PARTY_NOTICES.md`.

When a path contains both software and documentation, the license follows the character of each file rather than the directory name alone. Unknown rights require exclusion or later explicit resolution.
